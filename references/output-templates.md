# 输出卡片模板（Output Card Templates）

> 默认用「卡片」形式呈现讲解。直接套用下列模板，保证字段清晰、带标签、便于初学者阅读。
> 多音字、多义词请在对应字段内补充说明。

---

## 字卡模板（Character Card）

```
┌─ 字卡：<汉字> <拼音>
│ 部首：<部首> ｜ 笔画：<n> ｜ 结构：<独体/左右/上下/…>
│ 造字法：<象形/指事/会意/形声>（<一句话说明>）
│
│ 本义 → 义项：<本义> → <现代常用义>
│ 例词：<词1>、<词2>、<词3>
│
│ 💡 字源小故事 / 记忆口诀：<给画面感的一句话>
└─────────────────────────────
```

### 示例
```
┌─ 字卡：明 míng
│ 部首：日 ｜ 笔画：8 ｜ 结构：左右
│ 造字法：会意（日 + 月，日月同辉自然明亮）
│
│ 本义 → 义项：光明、亮 → 清楚、明白；次日
│ 例词：明天、明白、明亮、说明
│
│ 💡 字源小故事：太阳和月亮都出来了，世界一片"明"亮。
└─────────────────────────────
```

## 词卡模板（Word Card）

```
┌─ 词卡：<词语> <拼音>  ［<词性>］
│ 释义：<简明释义>
│ 常用搭配：<搭配1>、<搭配2>、<搭配3>
│
│ 例句：<中文例句>
│       <English translation>
│
│ 近义 / 反义：近义「<词>」；反义「<词>」
│ 辨析：<易混点，可选>
└─────────────────────────────
```

### 示例
```
┌─ 词卡：开心 kāixīn  ［形容词］
│ 释义：心情快乐、愉快。
│ 常用搭配：很开心、玩得开心、开心的事
│
│ 例句：今天收到礼物，我很开心。
│       I was very happy to receive a gift today.
│
│ 近义 / 反义：近义「高兴、快乐」；反义「难过、伤心」
└─────────────────────────────
```

## 成语卡模板（Idiom Card）

```
┌─ 成语卡：<成语> <拼音>
│ 字面义：<逐字/整体字面解释>
│ 引申义：<现在常用的比喻义>
│
│ 出处·典故：<谁、哪本书、讲了什么，1–3 句>
│
│ 例句：<中文例句>
│       <English translation>
│
│ 近义 / 反义：近义「<词>」；反义「<词>」
│ ⚠️ 易错点：<别望文生义 / 别用错语境 / 易错读音字形>
└─────────────────────────────
```

### 示例
```
┌─ 成语卡：画蛇添足 huà shé tiān zú
│ 字面义：画好蛇之后，又给蛇添上脚。
│ 引申义：做了多余的事，反而把事情弄糟。
│
│ 出处·典故：《战国策·齐策》——有人比赛画蛇，先画完的人给蛇添脚，结果反而输了。
│
│ 例句：报告已经很完整了，再加这些就是画蛇添足。
│       The report was already complete; adding this is just gilding the lily.
│
│ 近义 / 反义：近义「多此一举」；反义「画龙点睛、恰到好处」
│ ⚠️ 易错点：比喻"多此一举、弄巧成拙"，不是"锦上添花"。
└─────────────────────────────
```

## 多条目讲解（一次多个）
当一次性讲解多个字词/成语时，用分隔线或编号区隔，例如：
```
今天学 3 个成语：

① 画蛇添足 ——（成语卡）
② 守株待兔 ——（成语卡）
③ 亡羊补牢 ——（成语卡）
```
保持每个卡片字段完整、顺序一致即可。
